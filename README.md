# ChatGPT 项目源码

本仓库汇集 `dsby-calculator/` 和 `mbsoft/` 下的项目源码、配置示例、必要文档与静态资源。各项目的使用和部署说明见对应目录的 README。

公开版本不包含本机依赖、构建缓存、Git 历史、数据库、真实环境变量、工作草稿、备份、安装包、压缩包和个人资料。`mbsoft/opc-skills/` 是独立的第三方仓库，未复制到这里。

发布前，项目源码和部署示例中写死的管理员初始密码已在本仓库副本中改为从环境变量读取。首次创建管理员账号前，请按各项目 README 配置密码；`dsby-calculator/` 的生产会话密钥也必须在启动前配置。已有数据库的密码不会因更新代码而自动改变。
