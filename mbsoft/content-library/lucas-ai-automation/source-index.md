## 六条故事线

1. 收入与客户来源：结果证明 → 客户从哪里来。
2. 报价自动化：老板提出需求 → 输入诊断 → 搭建难点 → 风险边界。
3. 设备工单：老板求助 → 现场访谈 → 发现单点依赖 → 微信报修转工单 → 修改产品。
4. 需求诊断：重复4小时 → 是否值得自动化 → 真需求靠追问得出。
5. 选择困难 App：个人痛点 → 做工具 → 上线 → 有人问链接。
6. 开发者日常：Codex、Agent、ChatGPT 使用体验。
