## 核心发现

Lucas 的有效内容不是“教 AI”，而是把内容写成客户购买前的判断过程：

1. 先出现一个具体老板和一项重复工作。
2. 不急着上 AI，先判断输入、规则、责任人和输出。
3. 用业务风险反对“一键自动化”。
4. 最后展示项目、收入或可运行产品，完成能力证明。

爆款是 `8月份智能体项目总结：交付4个，收入12w`（952 赞），第二名 `上篇12w的AI项目很多人问：怎么找的客户？`（122 赞）。其余多数低于 20 赞。真正放大传播的不是工具教程，而是“明确金额 + 项目数量 + 客户从哪里来”。
