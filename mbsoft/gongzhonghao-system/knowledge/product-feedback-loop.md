# 产品反馈闭环方法论 · Product Feedback Loop

> 关闭「销售 → 产品」和「产品 → 流量」两个回路。

## 回路一：销售 → 产品

```
客户异议/反馈 → 聚类 → 需求优先级(RICE) → 迭代 → 验证
```

**关键**：不要等「大版本」，每 2 周一个小迭代，快速响应客户真实痛点。

## 回路二：产品 → 流量

```
交付案例 → 提炼素材 → 选题/内容 → 获客
```

**关键**：每个成交案例都必须能变成 1 篇内容。这是内容选题的「永不枯竭来源」。

## 案例素材结构（统一）

```
## 案例：[客户匿名代号]

### 客户背景
行业 / 规模 / 现有系统 / 团队情况

### 遇到的问题
（客户原话 + 量化描述）

### 我们的方案
做了什么 / 为什么这么做 / 关键决策

### 量化结果
示例格式（真实案例替换）：
    指标A：X → Y（+Z%）
    指标B：...

### 客户原话
（一段真实反馈，匿名）

### 可复用要点
- 适用于 [什么场景]
- 不适用于 [什么场景]
```

## 定价锚定原则

- **锚定价值，不锚定成本**：定价 = 客户获得的可量化价值 × 10%-30%。
- 若客户说「贵」→ 99% 是「价值没被讲清楚」或「产品拆分不合理」，而不是价格本身。
- 三级产品降低决策门槛：引流品（获客）→ 核心品（利润）→ 利润品（高毛利）。

## 交付即营销

**交付过程本身就是内容素材：**
- 每周一个「交付复盘」片段 → 选题池。
- 客户的「aha moment」 → 钩子素材。
- 踩过的坑 → 避坑型内容。

> 项目做得好，内容自然有；内容做得多，项目自然来。**这是整套系统最强的飞轮。**
