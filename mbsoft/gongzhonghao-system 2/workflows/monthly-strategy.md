# 月战略 · Monthly Strategy

> 每月最后一个周五执行，约 2 小时。目标是「校准流量-销售-产品三角的资源分配」。

## 核心动作：三角校准

```
                ┌──────────┐
                │   流量    │
                └────┬─────┘
                     ↓
                ┌──────────┐
                │   销售    │
                └────┬─────┘
                     ↓
                └──────────┘
                     ↑
                ┌──────────┐
                │   产品    │
                └──────────┘
```

**问自己一个问题：当前三角中，哪个角最弱？下月资源该往哪倾斜？**

## 执行步骤

### 1. 算三段转化率（monthly_calibrate.py）
```bash
python scripts/monthly_calibrate.py
```
输出各段转化率 vs 基准，自动标红缺口。

### 2. 判断最堵环节（对照基准）

| 环节 | 健康基准 | 低于 → 说明 |
|---|---|---|
| 阅读 → CTA 点击 | 3%-8% | 内容/钩子问题 |
| CTA 点击 → 加微 | 30%+ | 钩子/落地页问题 |
| 加微 → 有效沟通 | 50%+ | 人群不精准/话术 |
| 有效沟通 → 成交 | 10%-30% | 销售/产品/定价 |

### 3. 校准资源分配

**关键原则：一次只修一个最堵的环节。**

| 最堵环节 | 下月资源倾斜 |
|---|---|
| 流量 | 加码渠道实验、选题原子迭代 |
| 销售 | 私域承接 SOP、成交话术、异议库 |
| 产品 | 需求优先级、定价拆分、交付迭代 |

### 4. 战略输出（填模板）

```markdown
# 月度战略 · YYYY-MM

## 一、三角健康度
- 流量：[指标] vs 基准 → 状态 [健康/告警]
- 销售：[指标] vs 基准 → 状态
- 产品：[指标] vs 基准 → 状态

## 二、最堵环节
[环节]，缺口 [x 个百分点]，证据 [数据/反馈]

## 三、下月主题（一句话）
「这个月我们只聚焦：[解决 X]」

## 四、资源分配
| 环节 | 本月投入 | 下月投入 | 调整理由 |
|...

## 五、关键实验（2-3 个）
1. 假设：[x] ｜ 变量：[只变一个] ｜ 验收：[指标] ｜ 止损线：[阈值]

## 六、OKR
- O：[月度目标]
- KR1：[量化指标]
- KR2：...
```

## 与周复盘的衔接
- 周复盘管「**战术**」（做什么），月战略管「**战略**」（聚焦哪）。
- 月战略定的「下月主题」，会约束接下来 4 周的选题方向。
- **月度决策必须可被周复盘验收** —— 拆成每周的可观测指标。
