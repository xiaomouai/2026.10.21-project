# 本地运行指南

## 一、环境准备（一次性）

**要求**：Python 3.9 及以上（3.8 也大概率可用）

```bash
# 检查版本
python3 --version
```

**最快方式**：直接用仓库里的 `start.sh`（Mac/Linux）或 `start.bat`（Windows），一键完成下面全部步骤。

## 二、三步启动

```bash
# 1. 进入目录
cd gongzhonghao-system

# 2. 安装依赖
pip install -r scripts/requirements.txt
#    （核心脚本只用标准库；pandas/matplotlib 是可选增强）

# 3. 初始化数据表
python scripts/daily_collect.py --init
```

看到 `[done] 初始化完成` 即成功。

## 三、验证安装（推荐跑一次）

```bash
python scripts/test_all.py
```

会依次执行：初始化 → 采集 → 发布队列 → 知识库同步 → 周复盘 → 月校准 → 备份。
全部通过会显示 `✅ ALL TESTS PASSED`。

## 四、日常使用

### 每天（照 workflows/daily-flow.md）
```bash
python scripts/daily_collect.py          # 采集 + 生成日报 + 异常标红
python scripts/daily_collect.py --notify # 采集后推送通知（需配 .env）
```

### 每周五
```bash
python scripts/weekly_review.py --save   # 生成周复盘并归档
```

### 每月末
```bash
python scripts/monthly_calibrate.py      # 三角校准，输出资源倾斜建议
```

### 发布文章
```bash
python scripts/publish_queue.py add "标题" --time "2026-09-15 20:30" --topic 1 --stage 流量
python scripts/publish_queue.py list
python scripts/publish_queue.py publish 1   # 真实 API 接入见 TODO
```

## 五、配置文件（按需）

```bash
cp config.example.yaml config.yaml   # 账号、渠道、阈值
cp .env.example .env                 # 密钥（企微 webhook、公众号 API 等）
```

> `.env` 和 `config.yaml` 已在 `.gitignore` 中，不会误提交。

## 六、接入真实数据（进阶）

脚本目前是「骨架」—— 采集/发布用的是占位逻辑，你在对应位置看到 `TODO` 标记：

| 文件 | 需接入 | 说明 |
|---|---|---|
| `daily_collect.py` | 公众号/企微/CRM API | 替换 `collect()` 里的占位 |
| `publish_queue.py` | 公众号发布 API | 替换 `do_publish()` 里的占位 |
| `.env` | webhook / API key | 通知与数据源 |

**最小可用原则**：即使不接任何 API，手工填写 `data/daily-metrics/YYYY-MM-DD.csv` 也能跑完整套 SOP，脚本负责汇总、报表、归因。

## 八、常见问题

**Q：Mac 上 `start.sh` 没权限？**
```bash
chmod +x start.sh && ./start.sh
```

**Q：Windows 用什么命令？**
用 `start.bat`，或 Git Bash / PowerShell 里跑同样的 `python ...` 命令。

**Q：数据存在哪？**
全部在 `data/` 目录（CSV），`archive/` 按月份归档，`backups/` 放压缩备份。都是纯文本，随时可迁移。

**Q：如何备份？**
```bash
python scripts/backup_archive.py
```

**Q：知识库怎么更新？**
沉淀有效原子到 `knowledge/`，然后 `python scripts/knowledge_sync.py` 重建索引（自动去重）。
